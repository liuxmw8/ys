GitHub Pages + Gist 同步步骤

  1. 仓库 Settings → Pages → Source 选择 Deploy from a branch。
  2. Branch 选择 main / root，保存后等待 GitHub Pages 部署。
  3. 创建 GitHub token：进入 https://github.com/settings/tokens，Classic token 只勾选 gist。
  4. 打开部署好的网页，填写 token 和文件名，点击 新建 Gist。
  5. 其他设备填写同一个 Gist ID、文件名和 token，即可读取或保存同一份预算数据。

这是个人工具方案，不适合多人同时编辑。同一时间多台设备保存时，后保存的数据会覆盖先保存的数据。
