GitHub Pages + Gist 同步步骤

  1. 新建 GitHub 仓库，例如 renovation-budget。
  2. 把本页面保存为 index.html，上传到仓库。
  3. 仓库 Settings → Pages → Source 选择 Deploy from a branch，Branch 选择 main / root。
  4. 创建 GitHub token：进入 https://github.com/settings/tokens，选择 Classic token，权限只勾选 gist。
  5. 打开部署好的网页，填入 token 和文件名，点击 新建 Gist。
  6. 创建成功后页面会自动填入 Gist ID。以后多台设备填写同一个 Gist ID、文件名和 token，即可读取/保存同一份预算。

注意：这是个人工具方案，不适合多人同时编辑。同一时间多台设备保存，后保存的会覆盖前保存的。
